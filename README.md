# PBA
Project Build Artifact - Program for building pseudo-native applications

# What is a lab?
These are test functions for the program that *might* make it into the main application. The laboratory component is written in Python, while the main program is written in Go.
# Sample of work
- Python 
    - The main function is building the project.
        - When building the Python project, you get the source code, a venv acting as a portable Python interpreter, and an .exe file serving as a launcher.
    - Let's say you have a config file; then, to run using the config, type `pba -s config`.
        - The internal VM reads the configuration and executes pre-prepared commands for you.
